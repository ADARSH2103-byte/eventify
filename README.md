# Eventify 🎉

Eventify is a modern event management web application built using React and Vite.  
It helps users explore, manage, and organize events with a clean and responsive UI.

## 🚀 Features

- Responsive Navbar
- Hero Section
- Services Section
- Multiple Pages with React Router
- Clean UI Design
- Fast Development using Vite

## 🛠️ Tech Stack

- React.js
- Vite
- React Router DOM
- CSS
